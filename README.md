# 拾语 Daily English

拾语是一个面向中国英语学习者的实用英语复习与学习应用。它主要服务于有一定英语基础、曾通过大学英语四级，但离开英语学习一段时间、希望重新找回语感的学习者。

课程从日常高频表达开始，逐步进入职场沟通、旅行与公共服务、中高级语法和观点表达。学习者可以按课学习词汇和语法，阅读带中文翻译的课文，通过朗读和卡片复习巩固内容，并使用速查表快速回顾常见语言形式。

## 学习内容如何组织

课程共有 50 课，分为四个难度阶段：

| 阶段 | 课程 | 学习重点 |
| --- | --- | --- |
| 复习基础 | 第 1–10 课 | 找回常见时态、冠词、数量表达和基础句型 |
| 日常进阶 | 第 11–30 课 | 工作、出行、健康、服务场景及常见复合句 |
| 中高级表达 | 第 31–40 课 | 阅读、文化、社会议题、数据和复杂观点 |
| 融会贯通 | 第 41–50 课 | 研究、演讲、反思、语篇衔接与综合表达 |

每课由以下内容组成：

- **课程信息**：课号、中文主题、英文标题、学习目标、阶段和预计用时。
- **课文**：英文段落及对应中文翻译。语法重点会在课文中高亮，并可单独打开语法讲解。
- **词汇**：目标为每课 100 个实用词，包含英文、中文释义和国际音标；词表与卡片模式可以互相切换，卡片复习支持记录“再来一次、有点模糊、记得”。
- **语法**：每课关联一个语法知识点。语法库包含结构、用法说明、例句翻译和选择练习，按学习阶段浏览。

词汇数据以 ECDICT 开放英汉词典的词频字段、音标和释义为基础，经脚本筛选后用于课程词表。学习优先级以高频和常见场景为准，课程主题也用于安排词汇出现顺序。当前各课的课文和部分词汇编排仍是内容初稿，独立课程文件提供了逐课校订和扩写的位置；发布正式课程前，应继续核验词频、音标、释义、搭配和课文语境。

## 其他学习工具

- **语法知识库**：50 个知识点，覆盖时态、条件句、被动语态、非谓语、名词性与定语从句、倒装、虚拟语气、语篇衔接等主题。
- **不规则动词表**：常用动词的原形、过去式、过去分词和中文释义，并提供语音朗读入口。
- **实用速查表**：高频连接词、职场搭配和易混词辨析。
- **语音**：优先调用浏览器的 Web Speech API。实际可用的英语声音由操作系统和浏览器决定；若浏览器没有可用语音，朗读功能可能不可用。
- **学习进度**：已完成课程、已掌握词汇和复习安排保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。

## 项目结构

```text
src/
  App.jsx                    页面与交互入口
  styles.css                 响应式样式和主题
  data/
    lessons.js               兼容旧引用的课程导出
    lessons/
      index.js               按课号聚合课程
      lesson-01.js            第 1 课完整数据
      ...
      lesson-50.js            第 50 课完整数据
    grammar.js                语法知识点、例句和练习
    references.js             不规则动词和速查表
    vocabulary.json           筛选后的词典数据
  lib/
    progress.js               本地进度读写
    speech.js                 浏览器语音朗读
scripts/
  build-vocabulary.mjs        从 ECDICT CSV 生成词汇 JSON
  split-lessons.mjs           从旧课程数据迁移为独立课程模块
tests/
  data.test.mjs               课程和语法数据校验
```

### 单课文件

每个 `lesson-NN.js` 默认导出一个课程对象，含课号、标题、摘要、难度阶段、对应语法编号、词汇数组和课文对象。词汇项使用以下字段：

```js
{ word: 'routine', zh: '日常安排', ipa: '/ruːˈtiːn/' }
```

课文对象包含英文标题、英文段落数组和位置对应的中文翻译数组。编辑单课内容时，直接修改该课文件；如新增课程，还需要同步更新 `lessons/index.js`、课程与语法关联，并调整对应测试。

`scripts/split-lessons.mjs` 是从旧版集中式课程数据迁移到 50 个文件时使用的脚本。当前模块已拆分完成，脚本默认拒绝覆盖已有课件。`npm run migrate-lessons` 会显式重新生成这些文件，只适用于从原始生成数据重新迁移时；日常编辑课程后不要运行该命令，以免覆盖手工修改。

## 运行项目

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

Vite 启动后，在终端显示的本地地址打开应用，通常是 `http://localhost:5173/`。

生产构建与测试：

```bash
npm test
npm run build
```

## 更新词汇数据

准备 ECDICT 项目的 `ecdict.csv` 文件后，设置 `ECDICT_SOURCE` 指向该文件，再运行：

```bash
ECDICT_SOURCE=/path/to/ecdict.csv npm run data
```

脚本会筛选带词频、音标和中文释义的条目，并更新 `src/data/vocabulary.json`。词典数据来源及其授权应随项目分发要求一并保留。ECDICT 使用 MIT License；其项目说明见 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)。
